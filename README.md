## 🔥 Featured Projects

### 🤖 JobPilot

> **AI-powered automated job-hunting platform**

A professional job-search automation platform designed to discover, normalize, score and organize job opportunities while assisting with CV tailoring and application workflows.

**Highlights**

- 🔎 Automated job discovery
- 🧹 Job normalization & deduplication
- 🎯 Job relevance scoring
- 📄 CV tailoring
- ✍️ AI-assisted application content
- 📊 Automated Excel reports
- 🤖 Telegram reporting
- ⚙️ Scheduled automation
- 🔐 Security and privacy-focused architecture

**Tech:**  
`TypeScript` `Node.js` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Zod` `Playwright` `GitHub Actions` `AI`

---

### 🔐 P-Accountant

> **Privacy-first local accounting assistant**

A local-first CLI application for processing payslips and working-hour documents while keeping sensitive financial information away from cloud AI services.

**Highlights**

- 🧾 Payslip processing
- ⏱️ Working-hours analysis
- 📊 Expected vs actual salary checks
- 🇩🇪 German student employment rules
- 🔍 OCR-based extraction
- 🧮 Mathematical validation
- 🔒 Local processing
- 🤖 Optional local AI explanations
- 🛡️ Privacy-first architecture

**Tech:**  
`TypeScript` `Node.js` `OCR` `OpenCV` `Python` `Ollama` `PostgreSQL`

---

### 🖼️ Intelligent Duplicate File & Photo Manager

> **Local duplicate and visually-similar file detection**

A privacy-focused application designed to find duplicate and visually similar files without uploading personal photos or documents to external services.

**Highlights**

- 📁 Recursive folder scanning
- #️⃣ Exact duplicate detection using hashes
- 👁️ Perceptual image hashing
- 🖼️ Visually similar photo detection
- 🔄 Renamed-copy detection
- 📂 Safe duplicate grouping
- 🧾 Operation history
- 🔒 Fully local processing

**Tech:**  
`Computer Vision` `Perceptual Hashing` `File Systems` `OpenCV` `Mobile Development`
